# 👻 Haunted Repo

*A Claude Code mod, just in time for Halloween.*

Every file Claude deletes comes back as a ghost. It drifts above your prompt and **whispers real lines of its lost code**, fading a little with every whisper, until you restore the file and set it free.

```
 ·    👻           👥                 ⛓          ⚰ 3 · witching hour
  “// TODO: write unit tests (never happened)  …from beyond” — sacrifice.js
```

## Install

```
/plugin marketplace add choaticpixels/HauntedClaudeMod
/plugin install haunted-repo@claude-mods
```

## What haunts you

| Event | What happens |
| --- | --- |
| `rm`, `git rm`, `del`, `Remove-Item`, emptying a file | 👻 The file's ghost rises, carrying its code |
| Deleting a folder, a glob or `node_modules` | 👥 **LEGION** rises: "for we are many" |
| An Edit that cuts 10+ lines | ∿ A wisp of the lost code lingers |
| Restoring the file | ✨ The ghost is laid to rest |
| A new session | Ghosts follow you there |

## Commands

- `/graveyard`: a pane of ASCII tombstones with dates and epitaphs
- `/seance [ghost] [question]`: the ghost answers in character, quoting its own code (uses Haiku)
- `/exorcise [name|all]`: banish a ghost. Some refuse, and bind themselves to your repo ⛓

## Easter eggs

There are a lot of them. Some hints:

- Some words are worth typing alone: a scare, a sneeze of respect, a doorstep question.
- Who are you gonna call?
- Never say *her* name three times.
- Force-pushing is how poltergeists are born.
- Keep an eye on your status line every so often. 🐈‍⬛
- The dead are louder at certain hours, and on one particular night.
- Old-school gamers know a code that lets the dead speak.
